연결 확인 중

시트를 이렇게 준비하면 바로 그려집니다

  1. 시트 탭 이름을 생산실적 으로 변경
  2. 1행 머리글 입력 — 필수 일자 카테고리 제품명 생산량 / 선택 목표량 투입량 불량량 비고
  3. 2행부터 하루에 한 줄씩 제품별로 입력 (날짜는 2026-08-04 형식)
  4. 우측 상단 공유 → 일반 액세스를 링크가 있는 모든 사용자 · 뷰어로 변경
  5. 이 페이지에서 ↻ 새로고침 클릭
생산량은 수율 계산에 쓰던 완제품 생산수량 그대로 넣으면 됩니다. 투입량까지 넣으면 수율(생산량 ÷ 투입량)이 자동으로 계산돼서 물량과 수율을 같은 화면에서 볼 수 있습니다.
연결이 막히면 — 시트에서 복사해 붙여넣기

구글 시트에서 머리글 포함 범위를 드래그해 Ctrl+C 한 뒤 아래에 붙여넣고 버튼을 누르면 같은 화면이 그려집니다. (사내망에서 외부 연결이 막힐 때 쓰는 우회 방법입니다.)
